# 看小说（aurabot-novel）

Aurabot 扩展模块：**读小说，学书里角色说话做事**。支持 `.txt` / `.docx` / `.epub` / `.pdf`。

> 大肥鱼（Aurabot 里的 QQ 伙伴）装了它之后，会把书读进书架、拆出人物卡，
> 然后学其中某个角色的性格、说话和做事方式 —— 不是扮演，也不会变成另一个人。

## 安装

**从 Release 下 zip，解压到 Aurabot 的扩展目录**：

```powershell
Expand-Archive .\aurabot-novel-1.1.0.zip -DestinationPath "$env:USERPROFILE\.dsh\plugins-data\aurabot\modules" -Force
```

解压后应该是 `...\modules\novel\index.mjs`。几秒内面板「扩展」页会出现「看小说」，显示「已启动」就好了。

- 升级：把 `modules\novel` 整个删掉，再解压新的。书架数据在 `modules-data\novel`，不会丢。
- 卸载：删掉 `modules\novel`；想连数据一起清空，再删 `modules-data\novel`。
- 这**不是** DSH 插件，不能 `dsh plugin add`；它是 Aurabot 的扩展模块，放在 `modules/` 下由 Aurabot 自己加载。

## 怎么把书给她

三种都行：

1. **直接发 QQ 文件**（推荐）：主人在私聊或群里发小说文件，她自动收下并开始读（设置里可以关）。
2. **放进书架文件夹**：
   `%USERPROFILE%\.dsh\plugins-data\aurabot\modules-data\novel\shelf\`
   放进去后 5 分钟内自动收书（或者发 `/小说 书架` 立刻收）。
3. **导入路径 / 网址**：`/小说 导入 D:\books\某本书.epub`、`/小说 导入 https://example.com/novel.txt`

支持的格式：

| 格式 | 说明 |
|---|---|
| `.txt` / `.md` | UTF-8、GBK / GB18030、UTF-16 都认；网页另存的 HTML 也能扒正文 |
| `.docx` | 按 Word 正文顺序抽，图片和批注不读 |
| `.epub` | 按书里的目录（OPF spine）顺序读，目录页、封面、注音不会混进正文；自动用书里写的书名 |
| `.pdf` | 只认**带文字层**的 PDF，见下面「PDF 的注意」 |

## PDF 的注意

PDF 是最容易出问题的一种，先看清楚：

- **扫描版 / 图片版读不了**：整页是图片的 PDF 没有文字层，只能先 OCR（比如用 WPS、Adobe、微信「提取文字」）转成 txt 再发。
  她会直接告诉你「这本 PDF 没有文字层」，不会把一本书默默读成空。
- **加密 PDF 读不了**：设了打开密码或权限保护的，需要先解开。
- **特殊字体排版的 PDF 可能抽不出来**：少数 PDF 用的是子集字体、又没带文字映射表（ToUnicode），抽出来会是乱码 —— 她也会明说，建议转成 txt / epub。
- 正文里的**换行会按段落拼回去**（PDF 的排版折行不是真段落），表格和公式可能会挤在一起，这不影响学角色，但别指望它排版精确。

## 命令（只有主人能用）

| 命令 | 作用 |
|---|---|
| `/小说` 或 `/小说 帮助` | 看说明 |
| `/小说 书架` | 有哪些书、读到哪了 |
| `/小说 读 书名` | 开始 / 接着读一本 |
| `/小说 进度` | 每本书读到第几段 |
| `/小说 停读` | 正在读的长篇先停下 |
| `/小说 角色` | 每本书里拆出了哪些人物 |
| `/小说 卡 名字` | 看某个人的详细人物卡 |
| `/小说 学 名字` | 学他说话做事（`/小说学名字` 也行） |
| `/小说 停` | 不学了，做回自己 |
| `/小说 删 书名` | 从书架删掉这本书 |

她自己也有一组工具：`novel_shelf`、`novel_recap`、`novel_read`、`novel_learn`。
所以你在聊天里说「你在看什么书」「罗辑是个什么样的人」「学学沈七说话」，她会自己用。

## 设置（面板「扩展」→「看小说」）

- **学角色（总开关）**：关掉就不往人格里加料，人物卡还在。
- **读完自动学主角**：默认开。读完一本自动学书里最主要的角色；想换人发 `/小说 学 名字`。
- **学的力度**：轻 / 中 / 重。越重，带的口头禅和腔调越多，占用提示词也越多。
- **每次读多少字** / **每本书最多读几段**：长篇会均匀抽样（首尾都会读），不是每段都读。
  默认 4500 字 × 30 段 ≈ 13.5 万字；想更准就调大，想省钱就调小。
- **自动收书** / **主人发小说自动读**：上面两种收书方式。
- **读小说时的额外要求**：会附在每次分析的提示词里，比如「重点学女性角色」「多收集口头禅」。

## 数据放在哪

`%USERPROFILE%\.dsh\plugins-data\aurabot\modules-data\novel\`

- `library.json`：书架、人物卡、现在学的是谁（每本书还记着格式、PDF 页数）
- `books/<id>.txt`：导入时抽出来的正文（已经转成纯文本，原文件删了也能重读）
- `notes/<id>.json`：分段阅读笔记（读到一半停下，下次接着读）
- `shelf/`：你往里面丢书的文件夹

删模块文件夹不会删这些数据；想彻底清空就删 `modules-data\novel`。

## 注意

- 读一本书要调模型很多次（每段一次 + 最后合并一次），会花时间，也会消耗模型额度。
- 模型偶尔会返回看不懂的内容：那一段会跳过，最后提示「有几段没读成」；失败太多会报错，重新发 `/小说 读 书名` 会重试失败的段。
- 她学的是**风格**，不是替你复述原著；人物卡里的「原话」只用来抓语气。
- 模块重新加载时，正在读的书会停住（标记为读了一半），发 `/小说 读 书名` 从没读的段接着来。
- 大文件慢一点：一份 20MB 的 PDF 抽文字要几百毫秒到一两秒（不联网、不装依赖，纯本地解）。
